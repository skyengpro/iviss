# IVISS PWA - User Installation Guide

## What is a PWA?

IVISS is now a Progressive Web App (PWA), which means you can install it on your phone or tablet just like a regular app from the app store. The best part? No app store needed!

## Benefits of Installing IVISS

✅ **Quick Access** - Launch from your home screen like any other app  
✅ **Works Offline** - Access cached data even without internet  
✅ **Faster Loading** - Loads instantly after installation  
✅ **Full Screen** - No browser bars, more screen space  
✅ **Auto Updates** - Always get the latest version automatically  
✅ **Less Data Usage** - Cached content means less downloading  

## How to Install

### 📱 Android (Chrome, Edge, Samsung Internet)

#### Method 1: Automatic Popup (Easiest)
1. Open IVISS in your browser
2. Wait a few seconds
3. A popup will appear asking "Install IVISS App"
4. Tap **"Install"**
5. Done! The app icon appears on your home screen

#### Method 2: Browser Menu
1. Open IVISS in Chrome
2. Tap the menu (⋮) in the top-right corner
3. Select **"Install app"** or **"Add to Home screen"**
4. Tap **"Install"**
5. The app icon appears on your home screen

### 🍎 iOS (Safari)

1. Open IVISS in **Safari** (must be Safari, not Chrome)
2. Tap the **Share** button (□↑) at the bottom
3. Scroll down and tap **"Add to Home Screen"**
4. Edit the name if you want (optional)
5. Tap **"Add"** in the top-right
6. The app icon appears on your home screen

### 💻 Desktop (Chrome, Edge)

1. Open IVISS in your browser
2. Look for the install icon (⊕) in the address bar
3. Click the icon
4. Click **"Install"**
5. The app opens in its own window

## Using the Installed App

### Opening the App
- Tap the IVISS icon on your home screen
- The app opens in full-screen mode
- No browser bars or tabs

### Offline Mode
- The app works even without internet
- You'll see an offline indicator when disconnected
- Cached data remains accessible
- Changes sync when you're back online

### Updates
- Updates happen automatically
- You'll see a notification when an update is available
- Tap **"Update Now"** to get the latest version
- Or wait - it updates next time you restart the app

## Troubleshooting

### "I don't see the install popup"

**Possible reasons:**
- You already installed the app
- You dismissed it recently (it will show again in 7 days)
- Your browser doesn't support PWA installation
- You're not using HTTPS (if on a custom domain)

**Solution:**
- Use the browser menu method instead
- Check if the app is already on your home screen

### "The app won't install on iOS"

**Make sure:**
- You're using Safari (not Chrome or other browsers)
- You're following the iOS-specific steps above
- You have enough storage space on your device

### "I want to uninstall the app"

**Android:**
1. Long-press the IVISS icon
2. Tap "App info" or drag to "Uninstall"
3. Confirm uninstall

**iOS:**
1. Long-press the IVISS icon
2. Tap "Remove App"
3. Tap "Delete App"
4. Confirm deletion

**Desktop:**
1. Open the app
2. Click the menu (⋮) in the title bar
3. Select "Uninstall IVISS"
4. Confirm

### "The app is showing old data"

**Solution:**
1. Pull down to refresh (if available)
2. Or close and reopen the app
3. Check if an update is available
4. Make sure you have internet connection

## Frequently Asked Questions

### Q: Is this the same as downloading from the app store?
**A:** It's similar! The main difference is you install directly from the website. No app store needed, and updates are automatic.

### Q: Does it use a lot of storage?
**A:** No, it's very lightweight. The app and cached data typically use less than 50MB.

### Q: Will it work without internet?
**A:** Yes, for basic features. You can view cached data and the app interface. Some features that require real-time data need internet.

### Q: Do I need to keep the browser app?
**A:** Yes, but you don't need to use it for IVISS. The installed app works independently.

### Q: Can I install on multiple devices?
**A:** Yes! Install on your phone, tablet, and computer. Your data syncs across devices when you log in.

### Q: Is it secure?
**A:** Yes, it uses the same security as the website. All data is encrypted, and you need to log in each time.

### Q: What if I lose internet while using the app?
**A:** The app continues to work with cached data. You'll see an offline indicator. When internet returns, everything syncs automatically.

### Q: How do I know if I have the latest version?
**A:** The app checks for updates automatically. You'll see a notification when an update is available.
